
# Sistema Integral de Gestion - Software FJ

## Descripcion

Software FJ es una aplicacion desarrollada en Python para gestionar clientes,
servicios y reservas mediante programacion orientada a objetos.

El sistema permite registrar clientes, administrar diferentes tipos de servicios,
crear y procesar reservas, cancelar operaciones y controlar errores mediante
excepciones personalizadas.

## Objetivo

Implementar un sistema organizado y robusto que aplique los principios de
programacion orientada a objetos y el manejo de excepciones para mejorar
la estabilidad y confiabilidad de una aplicacion.

## Funcionalidades

- Registro y validacion de clientes.
- Gestion de servicios especializados.
- Reserva de salas.
- Alquiler de equipos.
- Asesorias especializadas.
- Creacion, confirmacion y cancelacion de reservas.
- Calculo de costos, descuentos e impuestos.
- Manejo de errores y excepciones personalizadas.
- Registro de eventos mediante logging.
- Simulacion de operaciones exitosas y fallidas.

## Estructura del proyecto

- excepciones.py: excepciones personalizadas.
- entidades.py: clase abstracta base.
- clientes.py: gestion y validacion de clientes.
- servicios.py: servicios especializados.
- reservas.py: gestion de reservas.
- sistema.py: administrador central del sistema.
- main.py: ejecucion y pruebas.
- logs/: registro de eventos y errores.

## Tecnologias utilizadas

- Python 3.
- Visual Studio Code.
- Git.
- GitHub.

## Ejecucion

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir la terminal.
4. Ejecutar el siguiente comando:

   python main.py
